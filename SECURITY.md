# Security policy / Politique de sécurité

Qohesion handles votes and personal information. Please report vulnerabilities privately through GitHub's **Report a vulnerability** button in the Security tab of this repository. Do not open a public issue.

We will acknowledge within 5 business days and aim to publish a fix and advisory within 90 days. Include steps to reproduce, affected version and impact.

The project is pre-alpha and has no supported releases yet.
