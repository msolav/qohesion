## English

### What this covers

The name "Qohesion", the logo (the circle whose tail is a check mark), the wordmark and the icons. It does not cover the phrase "Decide together", which is a common expression, or the code and documents, whose licences are in [LICENSING.md](../LICENSING.md).

### Why there is a policy

The code licence lets anyone run and change the software. It does not tell a voter who is running the installation in front of them. A look-alike service that uses the name on a page where people vote could mislead them about who holds their data and who counts the votes. This policy keeps the name tied to what it actually refers to.

### Permitted without asking

1. Saying that Qohesion is used, in plain text: "voting with Qohesion", "built with Qohesion", "this organization hosts a Qohesion installation".
2. Showing the unmodified logo, at a legible size and linked to the project, to say that Qohesion is used.
3. Running an installation under the organization's own name, with the mention "powered by Qohesion" and a link to the project.
4. Writing about Qohesion accurately: articles, reviews, tutorials, talks and comparisons.
5. Redistributing an unmodified official release under its name.
6. Translating the documents and the interface. The name is not translated.

### Written permission required

1. **A modified version under the name.** A modified version takes its own name and logo. The mention "based on Qohesion" is permitted if the text states that the version is modified. The source of a modified version is published as the AGPL requires.
2. **A hosted service named after it.** A service, domain name, app or social account whose name contains "Qohesion", or a name confusingly close to it, requires permission. The offer may be described as "hosting for Qohesion".
3. **Merchandise** that carries the name or the logo.
4. **A changed logo:** recoloured, animated, cropped, or used as the logo of something else.
5. **Any claim of endorsement,** partnership, certification or official status.

### The official service

Only the service run by the project owner may call itself the official Qohesion service. Its address is published on qohesion.app. An installation at any other address is not the official service, even if it runs unmodified code.

### Asking permission or reporting a misuse

Requests go to [contact address] and state who is asking, the intended use and where it will appear. Requests are answered within [15 business days].

### Changes to this policy

Changes are listed in the [changelog](../CHANGELOG.md). A use that followed the policy when it began has at least [60 days] to adjust after a change.

## Français

### Ce que couvre cette politique

Le nom « Qohesion », le logo (le cercle dont la queue est une coche), le mot-symbole et les icônes. Elle ne couvre pas l’expression « Décidons ensemble », qui est courante, ni le code et les documents, dont les licences figurent dans [LICENSING.md](../LICENSING.md).

### Pourquoi une politique

La licence du code permet à quiconque d’exploiter et de modifier le logiciel. Elle n’indique pas à une personne qui vote qui exploite l’installation qu’elle a devant elle. Un service qui imite Qohesion et utilise son nom sur une page de vote pourrait tromper les gens sur qui détient leurs données et qui compte les votes. Cette politique garde le nom lié à ce qu’il désigne vraiment.

### Permis sans demande préalable

1. Dire que Qohesion est utilisé, en texte simple : « vote avec Qohesion », « conçu avec Qohesion », « cette organisation héberge une installation de Qohesion ».
2. Montrer le logo non modifié, à une taille lisible et avec un lien vers le projet, pour indiquer que Qohesion est utilisé.
3. Exploiter une installation sous le nom de l’organisation, avec la mention « propulsé par Qohesion » et un lien vers le projet.
4. Écrire sur Qohesion de façon exacte : articles, comptes rendus, tutoriels, conférences et comparaisons.
5. Redistribuer une version officielle non modifiée sous son nom.
6. Traduire les documents et l’interface. Le nom n’est pas traduit.

### Permission écrite requise

1. **Une version modifiée sous ce nom.** Une version modifiée prend son propre nom et son propre logo. La mention « basé sur Qohesion » est permise si le texte indique que la version est modifiée. Le code source d’une version modifiée est publié comme l’exige l’AGPL.
2. **Un service hébergé qui porte ce nom.** Un service, un nom de domaine, une application ou un compte de réseau social dont le nom contient « Qohesion », ou un nom qui s’y confond, exige une permission. L’offre peut être décrite comme de l’« hébergement pour Qohesion ».
3. **Des articles promotionnels** qui portent le nom ou le logo.
4. **Un logo modifié :** recoloré, animé, rogné, ou utilisé comme logo d’autre chose.
5. **Toute affirmation d’appui,** de partenariat, de certification ou de statut officiel.

### Le service officiel

Seul le service exploité par le propriétaire du projet peut se dire le service officiel de Qohesion. Son adresse est publiée sur qohesion.app. Une installation à toute autre adresse n’est pas le service officiel, même si elle exécute du code non modifié.

### Demander une permission ou signaler un abus

Les demandes sont adressées à [adresse de contact] et indiquent qui les présente, l’usage prévu et l’endroit où il paraîtra. Il y est répondu dans un délai de [15 jours ouvrables].

### Changements à cette politique

Les changements sont inscrits au [journal des modifications](../CHANGELOG.md). Un usage conforme à la politique au moment où il a commencé dispose d’au moins [60 jours] pour s’adapter après un changement.
